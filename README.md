# 🧑‍🍳 My Chef

A React app that generates recipes from the ingredients you already have at home — powered by Google's Gemini AI.

## Features

- Add ingredients to your kitchen list
- Delete ingredients you don't want
- Generate a full recipe using Gemini AI
- Chat with "Chef Bot" for help and cooking tips
- Responsive design (works on mobile & desktop)

## Tech Stack

- **React** (Vite)
- **Lucide React** (icons)
- **Google Gemini API** (recipe + chat generation)
- **CSS** (custom styling)
